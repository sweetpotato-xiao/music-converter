# 音乐解密转换器

把音乐平台下载的**加密音频**还原成可以直接播放的格式。

网易云音乐的 `.ncm`、QQ音乐的 `.mflac` / `.mgg` —— 这些文件拷到车机、U 盘、播放器、手机上，往往显示「不支持格式」。
本工具在**你自己的电脑上**把它们还原成 MP3 / FLAC / OGG。

带一个浏览器图形界面，不用记命令，不用装 Python。

---

## 特点

- **本地运行** —— 音频文件从头到尾不出你的电脑，不上传任何服务器
- **离线可用** —— 不需要联网，不需要登录音乐账号
- **图形界面** —— 浏览器里点几下就行，不需要命令行基础
- **批量处理** —— 整个文件夹一次转完，自动识别格式
- **保留音质** —— FLAC / OGG 原样输出，不做二次压缩转码
- **保留信息** —— 内嵌封面、歌名、歌手、专辑等标签

## 支持的格式

| 平台 | 输入格式 | 输出格式 |
|---|---|---|
| 网易云音乐 | `.ncm` | MP3 / FLAC |
| QQ音乐 | `.mflac` `.mflac0` `.mgg` `.mgg0` `.mgg1` `.mggl` `.mmp4` `.qmcflac` `.qmcogg` `.qmc0` `.qmc2` `.qmc3` `.qmc4` `.qmc6` `.qmc8` `.tkm` `.bkc*` | FLAC / OGG / MP3 |

输出格式由原始文件的音质决定，不做转码。

## 使用方法

### 方式一：下载打包好的 exe（推荐）

1. 到本仓库的 **Releases** 页面下载最新的 `音乐解密转换器.exe`
2. 双击运行，浏览器会自动打开操作界面
3. 选择文件夹 → 勾选歌曲 → 选择输出目录 → 开始转换

**不需要安装 Python 或任何其他软件**，单文件，双击即用。

> **首次运行的两个提示**
>
> 1. Windows 可能弹出蓝色的「Windows 已保护你的电脑」警告 —— 因为 exe 没有代码签名。
>    点「更多信息」→「仍要运行」即可。
> 2. 部分杀毒软件可能误报。这是 PyInstaller 打包程序的已知行业性问题（特征码误判），
>    添加信任即可。

### 方式二：从源码运行

需要 Python 3.8 或更高版本，无第三方依赖。

```bash
git clone https://github.com/sweetpotato-xiao/music-converter.git
cd music-converter
python server.py
```

也可以直接双击 `启动 音乐解密转换器.bat`。

## 常见问题

**Q：转换后的文件在哪里？**
在你选择的输出目录里。原始加密文件不会被删除。

**Q：输出目录里已有同名文件怎么办？**
会被覆盖。这样重复转换不会生成一堆副本。

**Q：为什么有的转出来是 FLAC，有的是 MP3？**
取决于你当初下载时选的音质。无损下载的原样输出 FLAC，标准音质输出 MP3。
本工具不做转码，只是还原。

**Q：歌词文件能处理吗？**
`.lrc` 歌词本来就是明文，直接和音频文件一起复制到外部设备即可，不需要转换。

**Q：转出来的歌在我的车机上还是放不了？**
部分老式车机和播放器不支持 FLAC。可以试试用其他工具把 FLAC 转成 MP3。

**Q：密钥需要联网获取吗？**
不需要。本工具处理的文件，密钥内嵌在文件尾部，全程离线。

## 工作原理

本工具**不重复实现解密算法**，而是把两个成熟的现成引擎包装成易用的图形界面：

| 引擎 | 负责 | 许可证 |
|---|---|---|
| [ncmdump](https://github.com/taurusxin/ncmdump) | 网易云 `.ncm` | MIT |
| [qmc_decrypt.py](https://github.com/HowenXu/qmc-decrypt) | QQ音乐 QMC 系列 | AGPL-3.0 |

`qmc_decrypt.py` 的算法移植自 [unlock-music](https://github.com/rong6/unlock-music) 的 Rust 实现。

本仓库贡献的是「界面 + 格式分发 + 交互封装」这一层。
